# Stupid Rip-Offs Made by AI

Games you've definitely played before. Just worse.

## Add a game
1. Make a new repo in the organisation, upload the game, then Settings → Pages → Branch: main → Save.
2. Edit `games.js` here: copy any line and change the title, words and repo name.

Small single-file games can also go straight into the `games` folder; use `file: "name.html"` instead of `url:`.
